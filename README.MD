# HedgeFundAI

Система алгоритмической торговли, использующая фундаментальный анализ и AI для генерации торговых сигналов.

## 🔧 Архитектура по слоям:

### 1. Data Layer (src/data)
- **market_data_service.py**: собирает фундаментальные и технические данные по тикерам из Finnhub.
  - Рассчитывает метрики: P/E, EPS growth, Revenue growth, momentum_3m, volatility и др.
  - Используется список тикеров из S&P500 (позиции 51–500, исключая топ-50 компаний).
  - Все данные кэшируются для снижения API-запросов.
  - Поддерживает работу с неполными данными.
  - **Особенности реализации**:
    - EPS Growth и Revenue Growth рассчитываются на основе квартальной финансовой отчетности (сравнение с аналогичным кварталом прошлого года).
    - Технические метрики (momentum, volatility) рассчитываются по дневным свечам из Finnhub API.
    - Данные сентимента генерируются симуляцией (требуется платная подписка API для реальных данных).

### 2. Analysis Layer (src/analysis)
- **scoring_engine.py**: ранжирует тикеры на основе метрик, выбирает топ-10 и боттом-10.
- **ai_reasoner.py**: генерирует инвестиционные тезисы через OpenAI с явными рекомендациями (BUY/SELL/HOLD).
- **Синхронизация сигналов**: система учитывает согласованность сигналов от скоринговой модели и AI рекомендаций, формируя список тикеров с подтвержденными обеими системами сигналами.

### 3. Trading Layer (src/trading)
- **portfolio_manager.py**: хранит состояние портфеля, отслеживает PnL, рассчитывает изменения.
- **alpaca_executor.py**: исполняет сделки через Alpaca.
- **risk_manager.py**: проверка лимитов, VaR, отслеживание рисков.

### 4. Rebalancing Logic
- Еженедельная ребалансировка.
- Поддержка различных сценариев (первая балансировка, регулярные изменения).
- Формирование торговых планов на основе целевой аллокации.

### 5. API Layer (src/api)
- FastAPI для доступа к данным, портфелю и аналитике.
- Ключевые эндпоинты:
  - `/universe/stocks`: получение всех акций с метриками и AI рекомендациями
  - `/ai/reasoning/{ticker}`: получение обоснования AI по конкретному тикеру
  - `/scoring/results`: результаты скоринговой системы
  - `/analysis/scores`: комбинированные результаты с синхронизацией AI и скоринговых сигналов

### 6. Frontend Layer
- Next.js приложение с интерфейсом для визуализации данных и управления портфелем
- Таблица вселенной активов с подсветкой перспективных инструментов
- Визуализация результатов анализа
- Интеграция с API сервером

### 7. Main (main.py)
- Поддержка различных режимов: сбор данных, расчет скоров, ребалансировка, API.

## 💡 Особенности реализации MarketDataService

### Источники данных
- **Finnhub API**: используется для всех типов данных
  - Фундаментальные метрики (PE ratio, Debt/Equity и др.)
  - Финансовая отчетность для расчета показателей роста
  - Исторические цены через endpoint stock/candles
  - Рекомендации аналитиков и целевые цены (price targets)
  - Данные о фактических и прогнозируемых EPS

### Расчет ключевых метрик
- **EPS Growth**: Рассчитывается как процентное изменение EPS по сравнению с аналогичным кварталом прошлого года, используя данные из квартальной отчетности (dilutedEPS).
- **Revenue Growth**: Рассчитывается как процентное изменение выручки по сравнению с аналогичным кварталом прошлого года.
- **Технические индикаторы**: Рассчитываются на основе дневных свечей.
- **Аналитический консенсус**: Рассчитывается на основе рекомендаций аналитиков (сильно покупать/покупать/держать/продавать/сильно продавать).

## 🧠 AI Reasoner

### Функциональность
- Генерация инвестиционных тезисов по каждому тикеру с использованием OpenAI API
- Извлечение конкретных рекомендаций (BUY/SELL/HOLD) на основе анализа
- Кэширование результатов для экономии запросов к API
- Поддержка обновления устаревших данных

### Интеграция со скоринговой системой
- API эндпоинт `/analysis/scores` предоставляет согласованные сигналы от обеих систем
- Для формирования потенциального портфеля используются тикеры, по которым:
  - Long позиции: положительный composite_score и рекомендация BUY от AI
  - Short позиции: отрицательный composite_score и рекомендация SELL от AI

### Кэширование
- Все данные кэшируются в директории `.cache/`
- TTL кэша по умолчанию - 1 день
- Поддержка принудительного обновления через `force_refresh=True`

### Метрики
- **Фундаментальные**: PE ratio, EPS growth, Revenue growth, Debt/Equity ratio, ROE, PEG ratio
- **Технические**: Momentum (3m), Volatility, Average volume, YTD price change
- **Аналитические**: Price targets (high, low, mean, median), Analyst consensus, EPS surprises, Rating trends

### Устойчивость
- Обработка ошибок API
- Поддержка частичных данных
- Резервные значения для недоступных метрик
- Логирование всех операций

## 🚀 Начало работы

### Установка зависимостей
```bash
# Backend
pip install fastapi uvicorn finnhub-python pandas python-dotenv requests lxml openai alpaca-py

# Frontend
cd frontend
npm install
```

### Настройка окружения
Создайте файл `.env` в корне проекта:
```
FINNHUB_API_KEY=ваш_ключ
ALPACA_API_KEY=ваш_ключ
ALPACA_API_SECRET=ваш_секрет
ALPACA_BASE_URL=https://paper-api.alpaca.markets/v2
OPENAI_API_KEY=ваш_ключ
```

### Запуск системы
```bash
# Backend API (из директории src/api)
export PYTHONPATH=$PYTHONPATH:/путь/к/проекту
python run_api.py --port 8001

# Frontend (из директории frontend)
npm run dev
```

### Запуск тестов
```bash
python test_market_data.py
```

## 📝 Примечания
- При использовании бесплатных API ключей некоторые функции могут быть ограничены.
- Для получения полной финансовой отчетности требуется подписка Finnhub, но система может работать с доступными данными.
- Система настроена на работу с 450 компаниями из S&P500 (исключая топ-50), что обеспечивает широкую диверсификацию и возможности для анализа.
